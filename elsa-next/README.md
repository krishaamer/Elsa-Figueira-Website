# Elsa Figueira production website

The active [elsafigueira.com](https://www.elsafigueira.com/) application, built with Next.js using the Pages Router and deployed on Vercel.

## Development

Run commands from the monorepo root:

```sh
pnpm install
pnpm dev
```

Or from this directory:

```sh
pnpm install
pnpm dev
```

The local site is available at [http://localhost:3000](http://localhost:3000).

## Production build

```sh
pnpm build
pnpm start
```

The Vercel project root directory should remain set to `elsa-next`.
